# Setcheck

[English](README.md) · **Русский**

Нативная macOS-утилита для подготовки DJ-плейлиста к проверке на YouTube:
небольшой MP4 со статичной картинкой, треклист с таймкодами и готовый текст описания.

Setcheck готовит файлы локально. Саму проверку Content ID выполняет YouTube после
загрузки. Отсутствие совпадений не означает разрешение правообладателя и не
гарантирует отсутствие будущих претензий. Setcheck не связан с YouTube или Google.

## Возможности

- Импорт Traktor NML, M3U/M3U8, rekordbox XML, аудиофайлов и папок.
- Поиск последней коллекции Traktor и выбор нужных плейлистов.
  При импорте нескольких плейлистов выбор начинается пустым, чтобы случайно не экспортировать всю коллекцию.
- Сохранение порядка треков; отдельный ролик на плейлист или общий сет.
- По умолчанию **180 секунд из середины каждого трека**, звук **AAC 384 кбит/с,
  48 кГц**, промежуточная обработка float32. Есть полные треки и режим 192 кбит/с.
- Картинка 640 × 360, 1 кадр/с, H.264; тёмный фон или собственный JPEG/PNG.
- Таймкоды по фактически декодированным PCM-семплам; без склеек с затуханием и пауз.
- Автоматическое разбиение на части до 11 ч 54 мин и в пределах описания YouTube.
  Очень длинный одиночный трек делится между видео, чтобы сохранить всё аудио.
- Удаление повторов пути; по умолчанию также по исполнителю, названию и близкой
  длительности внутри плейлиста или общего сета. Удалённые дубли попадают в отчёт.
- Недоступные треки блокируют подготовку, пока явно не разрешён их пропуск.
- Прогресс, отмена, открытие результата в Finder и копирование треклиста.
- Исходная музыка, коллекции Traktor и базы rekordbox не изменяются.

Интерфейс на русском языке. Поддержка FFmpeg включает FLAC, WAV, AIFF, MP3,
M4A, OGG и Opus.

## Установка и использование

Откройте `dist/Setcheck-1.0.0-macos-arm64.pkg`, установите приложение и запустите
**Setcheck** из «Программ» или через Spotlight. Терминал, Python и Homebrew для
работы упакованного приложения не нужны. Подпись приложения локальная ad-hoc;
установщик не подписан сертификатом Developer ID и не нотариализирован Apple.

**Текущий локальный установщик для Apple Silicon требует macOS 26 или новее:**
встроенные библиотеки FFmpeg собраны под macOS 26. Исходники Swift рассчитаны
на macOS 14+; каждая сборка определяет свой минимум по всем вложенным библиотекам.

1. Перетащите плейлист, файлы или папки в окно, используйте **⌘O** или «Из Traktor».
2. Выберите плейлисты и настройки. Нажмите «Подготовить», проверьте части и замечания.
3. Нажмите «Экспортировать». По умолчанию результат в `~/Movies/Setcheck`.
4. В каждой папке результата: `video.mp4`, `tracklist.txt`, `description.txt`,
   `report.txt`. Существующие результаты не перезаписываются.
5. Вручную загрузите MP4 в [YouTube Studio](https://studio.youtube.com/), вставьте
   `description.txt`, выберите «Ограниченный доступ» и дождитесь шага «Проверки».
   Сопоставьте время совпадения с треклистом и позже проверьте ограничения видео.

Фрагмент проверяет только выбранную часть трека. Для отправки всего содержимого
выберите полные треки. Видео длиннее 15 минут требуют подтверждения аккаунта
YouTube; предел загрузки — 12 часов или 256 ГБ. Описание ограничено 5000 знаками;
Setcheck дополнительно ограничивает UTF-8 байты. Таймкоды каждой части начинаются с нуля.

- [Инструкция YouTube по загрузке и проверкам](https://support.google.com/youtube/answer/57407?hl=ru)
- [Длительность загрузки и подтверждение аккаунта](https://support.google.com/youtube/answer/71673?hl=ru)

## Сборка и тесты

Для сборки: macOS, Swift 6+, Python 3, Command Line Tools или Xcode и FFmpeg/ffprobe:

```sh
brew install ffmpeg
scripts/test.sh
scripts/build-installer.sh
open dist/Setcheck.app
```

`build-app.sh` включает FFmpeg, ffprobe и все несистемные dylib в приложение,
исправляет пути загрузчика в копиях, собирает уведомления сторонних компонентов
и ставит локальную подпись. Исходная установка FFmpeg не меняется. Упаковка уже
собранного приложения: `scripts/build-installer.sh --skip-build`.

Тесты проверяют импорт и порядок, повреждённый XML и внешние сущности, потерянные
ссылки, дубли, разбиение, настоящий короткий H.264/AAC-экспорт, PCM-таймкоды,
обложку, отмену, очистку ошибок и защиту от перезаписи. Музыка для тестов синтетическая.
Сборки, медиадвижок и пользовательские медиа не включаются в Git.

Создайте репозиторий и отправьте `main` либо запустите `scripts/publish.sh` при
настроенном `gh`. Скрипт рассчитан на `mrzenxxx/setcheck`. Публичная раздача
установщиков со сторонним медиадвижком требует предоставления соответствующих
исходников и соблюдения его лицензий: [THIRD_PARTY.md](THIRD_PARTY.md).
